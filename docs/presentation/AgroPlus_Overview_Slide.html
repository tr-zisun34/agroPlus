Design Principles

✓

Grounded, not generative — every number the assistant states comes from a real tool call, not model knowledge.

✓

Provenance over estimation — yield/price/cost always traced to a named dataset.

✓

Rotation-safe by default — the same exclusion rule applies everywhere crops are ranked.

✓

Component-based backend — ML, economics, weather, and chat are independently replaceable services.

✓

One codebase, two languages — Flutter + full English/Bangla localization, agent replies in-language.
